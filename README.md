# 📚 Books To-Do App

A simple **Books To-Do application built with Ruby on Rails and MySQL**.

This project was created to learn and practice Rails fundamentals such as **MVC architecture, routing, Active Record, migrations, forms, and CRUD operations**.

## 🚀 Features

* Add a new book
* View all books
* Edit book details
* Delete books
* Store book data in MySQL
* Manage database changes using Rails migrations

### Book Details

Each book contains:

* Title
* Author
* Status
* Genre

## 🛠️ Tech Stack

* **Ruby:** 3.4.10
* **Ruby on Rails:** 8.1.x
* **Database:** MySQL 8.x
* **ORM:** Active Record
* **View:** ERB

## 🔄 CRUD Operations

The project implements all four basic CRUD operations:

* **Create** — Add a new book
* **Read** — Display books
* **Update** — Edit existing book details
* **Delete** — Remove a book
